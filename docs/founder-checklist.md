# Founder checklist: what you provide
Claude Code writes the code. These items need you. Tick them off as you go.

## Before and during M0 (calculation service)
- [ ] Claude Code access: paid Claude plan, laptop with a terminal
- [ ] Two reference programs installed (e.g. Jagannatha Hora and one other)
- [ ] Golden set: 40-50 birth charts (invented or consented data only) with reference values in data/golden/
- [ ] Conventions read from the reference software and recorded in docs/decisions-and-open-questions.md: ayanamsa, mean vs true node, dasha year length, dasha balance method, house system
- [ ] School chosen (default: Parashari + Lahiri + Vimshottari)
- [ ] Astrologers: one paid rule author, two independent checkers (draft rule table needed by M1)
- [ ] Confirm assumption: sensitive questions (health, death, investment) are declined with a pointer to a professional
- [ ] Confirm assumption: timing is framed as favourable/difficult periods, not promised outcomes

## M1 (web funnel)
- [ ] LLM API key
- [ ] WhatsApp Business API access and approved OTP template
- [ ] SMS provider and DLT registration (if you want the SMS fallback)
- [ ] Place-search (geocoding) provider
- [ ] Database and Redis hosting
- [ ] Domain name
- [ ] Product name and brand
- [ ] Approve: suggested-question chips, disclaimer and consent wording, English and Hindi landing copy
- [ ] Approve: 30+ red-team questions for the guardrails

## M2 (payments and PDF)
- [ ] Business entity and GST status decided (check with an accountant)
- [ ] Payment gateway account (Razorpay or Cashfree); check their current requirements
- [ ] Price decision: Rs 199 or Rs 299
- [ ] Refund policy wording
- [ ] PDF design approval (layout, fonts, cover)
- [ ] Hindi reviewer (native speaker) for the first 20 reports

## M3 (admin, review, soft launch)
- [ ] Test budget (an amount you can lose completely)
- [ ] Ceiling on cost per paid report
- [ ] Meta ad account, Instagram business account, landing-page tracking, ad creatives
- [ ] Legal review: privacy policy, terms, data-protection check
- [ ] Astrologer sign-off on 20 sample reports
- [ ] Support channel (email or WhatsApp number) for refunds and report problems
- [ ] Your time to hand-check the first orders

## M4 (Android)
- [ ] Google Play developer account
- [ ] App name, icon, screenshots, privacy policy URL
- [ ] Decision on how to sell reports inside the app, after reading Google's current billing rules

## Throughout
- [ ] Read each milestone's test report and summary
- [ ] Answer Claude Code's astrology and convention questions from your reviewers or reference software; never let it guess
